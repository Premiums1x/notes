0903 在index页以及新增/编辑弹窗组件，写了新加的启用、停用的逻辑，如果没有单独接口可以利用edit做回填，然后拉取一遍最新数据也可。这种弹窗新增情况下，需要对实际表单做清空，编辑的情况下涉及到获取详情回填，但因为考虑到接口是全量更新，都需要保存一份列表数据对象的详情，尽管表单中并不涉及某些字段，但是需要在最终save 方法调用保存时，还是要在入参将这些详情的字段回填一遍，编辑的话就拷贝，然后可能有覆盖现象。新增一遍都是在这些详情字段上加上表单的字段以及一些必需的，如row.id等

- $ref是组件引用，获取当前组件内部的某一个具体 DOM 元素或子组件，需加上ref属性。
- 全局挂载方法 如this.$confirm this.$message，因为Element UI在创建Vue实例后全局注册了Vue.use(ElementUI), ,这些原本是原型链上的方法，被Element UI 提供的方法给覆盖了。变成了Element UI 提供的编程式弹窗。不需要在 `<template>` 里面写标签，直接用 js 函数调用，它会自动在页面上动态创建 DOM 并弹出。
- Vue 框架 内置方法：this.$nextTick this.$emit this.$set Vue 框架自身提供的核心 API。
- 路由与状态库 this.$router this.$store Vue Router 和 Vuex 注入的全局导航和状态管理。
