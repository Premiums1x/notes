思路：最终都是为了渲染在页面上服务，所做的都是为了加工成页面需要的结构。

## 数组
1. filter过滤筛选
2. map对数组项进行转换，可能包装为其他结构：
```js
const options = users.map(item => ({ value: item.id, label: item.name }))
```
常用
- 拓展运算符`...`,
- `.?`链式运算符：是否存在
3. find找元素
4. some判断有没有
5. sort排序，如果后端返回数据无需
6. 去重，常借助Set结构
7. `reduce`：统计、分组、汇总


## 对象：
1. 直接取字段
2. 解构，如：
```js
const { name, age } = user

//等价于：
const name = user.name
const age = user.age
```
3. 展开运算符`...`
4. 处理null/undefined数据，防御性编程：`const name = user.name || '暂无'`、
`const name = user.name ?? '暂无'`
5. 对于嵌套对象，判断是否存在的防御性链式调用：`?.`以及 `??`:`const city = user.address?.city ?? '暂无'`

实战案例实例：
```js
async getList() { 
	const res = await getUserList() 
	this.total = res.data.total ?? 0 
	this.tableData = (res.data.list ?? []) .filter(item => item.status !== -1) .map(item => ({ ...item, statusText: item.status === 1 ? '启用' : '禁用' }))
 }
```
