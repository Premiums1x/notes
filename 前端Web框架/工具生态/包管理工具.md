1.先要知道Nodejs的作用：**运行 JavaScript 的环境**
2.**npm / yarn** = 帮你管理依赖、安装包、运行脚本的包管理器
1. npm 是什么

- **npm = Node Package Manager**
    
- 最大特点：**随 Node.js 一起安装**（你装了 Node，通常就自带 npm）
    
- 你用它来：
    
    - `npm install` 安装依赖到 `node_modules`
        
    - 生成/维护锁文件：`package-lock.json`
        
    - 跑脚本：`npm run dev`
 2.  yarn 是什么

- **yarn 是另一套包管理器**（最初由 Facebook 等推动，用来改进当年 npm 的安装速度/一致性体验）  

  *需要注意的是*：**一般不是直接自带一个 yarn 命令**。但在不少 Node 版本的官方发行版里，会带 **Corepack**（实验性工具），Corepack 可以帮你“按项目”使用 Yarn / pnpm（需要你执行启用）。
    
- 你用它来做同样的事：
    
    - `yarn install`
        
    - 锁文件：`yarn.lock`
        
    - 跑脚本：`yarn dev`

运行过程：
1. **读 `package.json`**：里面写了项目依赖（dependencies/devDependencies）和脚本（scripts）
    
2. **去仓库下载包**：把依赖下载安装到 `node_modules`
    
3. **写“锁文件”保证一致性**：确保你和队友安装出来的版本尽量一致
    
4. **执行脚本**：比如启动开发服务器、打包、跑测试
    

> “锁文件”非常关键：它决定你装到的**精确版本**。  
> npm 用 `package-lock.json`，yarn 用 `yarn.lock`。


常用的命令：
1.安装依赖(最长用)
```js
npm install
yarn
```

2.安装一个包：
```js
npm i axios
yarn add axios
```

3.安装开发依赖：
```js
npm i -D webpack
yarn add -D webpack
```

4.运行脚本
```js
npm run dev
yarn dev
```

5.删除包
```js
npm uninstall axios
yarn remove axios
```
