# 前端面试复习总览

> 用途：记录校招 / 初级前端面试中真正需要能“口述出来”的知识点。
> 
> 维护方式：学习笔记继续放在原有技术目录中；这里重点记录面试表达、易错点和掌握情况。

## 当前阶段判断

目前的主要问题不是“完全不会”，而是：

- 很多概念已经听过，也能说出主干；
- 口述时容易顺序混乱、术语不够准确；
- 想一次性把所有细节讲完整，反而容易卡住；
- 更适合采用“先讲主干，再等追问展开”的答题方式。

建议每个知识点都整理为：

```text
一句话定义
+
核心区别
+
一个例子
+
面试版回答
```

## 当前答题策略

### 浏览器渲染流程

先讲：

```text
HTML -> DOM
CSS -> CSSOM
DOM + CSSOM -> Render Tree
-> Layout
-> Paint
-> Composite
```

### URL 到页面展示

先讲：

```text
解析 URL
-> DNS
-> IP
-> TCP
-> TLS（HTTPS）
-> HTTP 请求
-> 响应
-> 浏览器渲染
```

### JavaScript 概念题

先回答定义和核心区别，不要一开始就追求非常底层。

例如 `var / let / const`：

```text
作用域
变量提升
是否允许重复声明
是否允许重新赋值
```

## 复习原则

面试时优先保证：

1. 主干顺序正确；
2. 关键术语不要说错；
3. 先回答 20~40 秒的主体内容；
4. 面试官继续追问时再展开细节。

目标不是把每道题背成一篇长文章，而是让知识形成稳定的口述模板。
