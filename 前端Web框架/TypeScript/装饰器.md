1. 类装饰器
基本语法：
```ts
function Demo(target:any){

  console.log(target);

}

  

@Demo

class Person{

  constructor(public name:string){}

}
```
target参数就是把要装饰的类拿到；
给类加装饰器相当于，执行这个装饰器的函数，并把类作为参数传入，这里的Demo会在类定义完成后执行。

等价于：

#### 举例：
```ts
function Demo(target:Function){

  console.log(target);

  // [object Obejct]

  

  //重写原型链上的方法:

  target.prototype.toString = function(this){

    return JSON.stringify(this)

    //将实例打印成JSON

  }

}

  

@Demo

class Person{

  constructor(public name:string){}

}
```

#### 替换被装饰的类
不在原型对象上追加/覆盖，而是直接返回新的类，既有被装饰类的内容，也有独特的属性、方法
```ts
type Constructor = new (...args: any[]) => {}

  

interface Person {

    getTime():void

}

  

function LogTime<T extends Constructor>(target: T) {

    return class extends target {

        createdTime: Date

        constructor(...args: any[]){

            super(...args)

            this.createdTime = new Date()

        }

        getTime(){

            return `该对象的创建时间是：${this.createdTime}`

        }

    }

}

  

@LogTime

class Person{

    name:string

    age:number

    constructor(name:string,age:number){

      this.name = name

      this.age = age

    }

}

  
  

const p1 = new Person("xp",11)
```

#### 属性遮蔽：（原型对象上已有的属性把要往实例对象上加的属性遮掉了）
![[Pasted image 20260509114116.png]]

this.age：往实例上追加属性，查看实例上没有后就去原型链上找，结果发现原型链上有我们刚加的age，就“拿过来用”，所以给age赋值是，是触发了原型链上age属性的setter

![[Pasted image 20260509115406.png]]
前写法：用一个value来缓存新值，会导致所有实例都拿到同一的值。
现：缓存新值放在实例自身身上：
	往实例上追加一个新属性，set给新属性赋值为修改后的新值，get返回的是实例上自身的新属性的值
