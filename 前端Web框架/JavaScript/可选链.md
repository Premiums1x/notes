搭配`arr.find()`经验：
`arr.find`返回数组中匹配到的第一个元素，若无匹配则返回`undefined`,后面加上`?.`的链式调用，表示如果找到了就继续访问这个元素的内容, 没找到就不**强行读取属性**，不报错

## 0 与 || 、?? 的关系（博客笔记）

> 来源：http://120.77.152.123:8088/posts/0%e5%92%8c%7c%7c ｜ 原发布日期：2026-07-15

JavaScript 中，数字 0 会被隐式转换为布尔值 false。 所以在使用“或”逻辑运算符来做“空值过滤”时，另一侧是null，如：`plusParam: row.plusParam || null`，这种时候，如果后端返回的0是一个实际需要的值，因为0被视为false，返回的会是null而非0.

解决方法：使用？？运算符。
