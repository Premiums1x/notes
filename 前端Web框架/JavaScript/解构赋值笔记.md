
解构赋值 就是**按数组或对象的结构，把里面的值直接拆出来赋给变量**。

## 数组解构

`const [a, b, c] = arr`

表示按位置赋值：

- a 对应第 1 项
- b 对应第 2 项
- c 对应第 3 项

相当于：

`const a = arr[0] const b = arr[1] const c = arr[2]`

## 对象解构

`const { name, age } = user`

表示按属性名取值：

- name 取 user.name
- age 取 user.age

## 核心区别

- 数组解构：看位置
- 对象解构：看属性名

## 一句话总结

**解构赋值就是在赋值时，不用一个个取值，而是按照数据结构直接把值拆出来给变量。**
