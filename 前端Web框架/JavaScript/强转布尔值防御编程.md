### 一、（双重逻辑非 `!!`）
`!!row.isRfid`
#### 语法原理

- 第一个 `!`：将原值转为布尔值并**取反**；
- 第二个 `!`：再次取反，恢复原来的真假逻辑，但此时类型已经变成标准的 `Boolean`（`true` 或 `false`）。

**转换效果举例：兼容后端返回类型**

| `row.isRfid` 原值      | `!row.isRfid` | `!!row.isRfid`（最终值） |
| -------------------- | ------------- | ------------------- |
| `true`               | `false`       | **`true`**          |
| `1`（部分后端习惯返 1）       | `false`       | **`true`**          |
| `false`              | `true`        | **`false`**         |
| `0`（部分后端习惯返 0）       | `true`        | **`false`**         |
| `null` / `undefined` | `true`        | **`false`**         |

### 二、数组filter里判Boolean防止后端接口返回脏数据（与情况一等价）
`filter(Boolean)` 
即：
`res.data.list.filter(Boolean);`
等价于：
`res.data.list.filter(item => Boolean(item)); // 即 item => !!item`
*目的*：剔除以下所有转为布尔后为 `false` 的元素：
- `null`
- `undefined`
- `""`（空字符串）
- `0`
- `false`
- `NaN`
