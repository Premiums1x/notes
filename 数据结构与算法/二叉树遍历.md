# 二叉树遍历

整体分为两种思想：BFS、DFS

1. BFS（广度优先搜索）

- 层序遍历：用队列实现，一层层遍历符合队列FIFO（先进先出）的处理顺序。当上一层节点完全出栈后，队列里的是下一层的所有节点（如果有下一层）

时间复杂度: O(n)访问每个节点 空间复杂度：最差情况下，即满二叉树时，遍历到最底层之前，队列中最多同时存在 （n+1）/ 2 个节点，占用 O(n)空间。

2. DFS（深度优先遍历） ,区别在于访问根节点时间， 一般使用递归实现。

- 前序搜索:

```
def pre_order(root: TreeNode | None):
    """前序遍历"""
    if root is None:
        return
    # 访问优先级：根节点 -> 左子树 -> 右子树
    res.append(root.val)
    pre_order(root=root.left)
    pre_order(root=root.right)
```

- 中序搜索

```
def in_order(root: TreeNode | None):
    """中序遍历"""
    if root is None:
        return
    # 访问优先级：左子树 -> 根节点 -> 右子树
    in_order(root=root.left)
    res.append(root.val)
    in_order(root=root.right)
```
中序变量得到的序列是“递增的”，因为二叉搜索树的特性，总会先遍历到值更小的节点。

- 后序搜索

```
def post_order(root: TreeNode | None):
    """后序遍历"""
    if root is None:
        return
    # 访问优先级：左子树 -> 右子树 -> 根节点
    post_order(root=root.left)
    post_order(root=root.right)
    res.append(root.val)
```

时间复杂度：O(n) 空间复杂度：O(n)，递归占用n个栈帧空间


如果考虑数据使用数组还是二叉搜索树进行存储：只有在多“增”，少删的情况下，数组性能更优，其余情况下二叉搜索树时间复杂度均为O(logn)

# 增删查：
## 查：
跟二分搜索思想一致

## 增
需要保持二叉搜索树“左子树 < 根节点 < 右子树”的性质，需要一个pre变量“记住前一个节点”，方便在其后进行插入。

## 删：
需要考虑该节点的度为0/1 /2 的情况
- 0 时直接删
- 1 时将待删除节点的子节点替换其原本位置即可
- 2 时需要先找到待删除节点，然后选用该节点左子树中最大值/右子树最小值对应的节点进行节点替换
假设选择右子树的最小节点，即为中序遍历的下一个节点
