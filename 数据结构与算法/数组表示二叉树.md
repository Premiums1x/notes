# 二叉树的数组表示：

二叉树若用链表表示：则每个存储单元为节点 TreeNode ，通过引用来保存指向关系。

也可用数组表示：由”映射公式“表示 节点间的关系，这个映射公式起到”指针“作用

- 完美二叉树：将所有节点按照层序遍历的顺序存储在一个数组中，则每个节点都对应唯一的数组索引。*（注意条件是”层序遍历“放在数组中）*,则映射公式：对任一个二叉树节点的索引i，都有该节点的左子节点索引为2i+1，右子节点索引位2i+2， 父节点的索引：(i - 1) // 2。
- 任意二叉树：一个节点的度可能为0、1、2，如果不显式表示None，那么这个数组序列就不能唯一标识一颗二叉树。
- 完全二叉树：这种二叉树的None节点一定在最后一层的靠右侧，所以这些节点在数组中一定是末尾处连续的None，可以忽略。

## 数组表示二叉树的优点、局限：

优点:

- 数组存储在连续的内存空间中，对缓存友好，访问与遍历速度较快。
- 不需要存储指针，比较节省空间。
- 允许随机访问节点。
- 然而，数组表示也存在一些局限性。

缺陷：

- 数组存储需要连续内存空间，因此不适合存储数据量过大的树。
- 增删节点需要通过数组插入与删除操作实现，效率较低。
- 当二叉树中存在大量 None 时，数组中包含的节点数据比重较低，空间利用率较低。
