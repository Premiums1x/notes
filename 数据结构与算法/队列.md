# 队列

“先来后到“，先进先出（FIFO）

### 实现：（与栈相似，数组、链表都能实现队列操作：push、pop、peek）

## 数组：

由于数组删除头元素的时间复杂度为O(n), 我们定义一个头元素的指针`front`、以及一个变量记录队列长度`size`，那么最后一个元素+1的位置就是`rear = front + size`, 插入时直接在这个索引插入即可。

基于此设计，数组中包含元素的有效区间为 [front, rear - 1]：

- 入队操作：将输入元素赋值给 rear 索引处，并将 size 增加 1 。
- 出队操作：只需将 front 增加 1 ，并将 size 减少 1 。

入队和出队操作都只需进行一次操作，时间复杂度均为 O(1)

不断进行入队和出队的过程中，front 和 rear 都在向右移动，当它们到达数组尾部时就无法继续移动了。为了解决此问题，要将数组视为首尾相接的“环形数组”。

对于环形数组，我们需要让 front 或 rear 在越过数组尾部时，直接回到数组头部继续遍历。这种周期性规律可以通过“取余操作”来实现

*基于数组实现的队列依然存在长度不可变问题，但可以通过”动态数组”改进。*

## 链表：

将头节点视为”队首“，尾节点视作”队尾“，入队在就在尾节点后新增节点，出队就更新头节点。
