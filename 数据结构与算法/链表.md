一般没有现成的LinkeList API，，除了Java的util包有封装好的LinkedList类，其他的不清楚。写算法时因为我们需要自己操作每一个节点内部的逻辑，通常自己写一个链表类。

```
class LinkedList{
    int val;
    LinkedList next;

    public LinkedList(int x){
          val = x;
    }
}
```

构建一个链表，顺序一般是：

- 初始化每个节点对象
- 确定好每个节点对象的指向

千万千万分清除**变量、引用、对象**，梳理好，不然很容易绕晕

```
ListNode P = n0.next;
ListNode n1 = P.next;
n0.next = n1;
```

就像这一段代码：

```
拿到n0指向的下一个节点对象的引用存到变量P；

拿到P指向的下一个节点，又因为P存的引用是n0的下个节点，所以`P.next == no.next.next`, P.next拿的是n0的下下个节点的引用；

最后让n0指向的下一个节点变为原本的下下个节点，从而跳过n0的下一个节点，实现将其删除的效果。
```

三种链表类型：

- 单向链表：即前面介绍的普通链表。单向链表的节点包含值和指向下一节点的引用两项数据。我们将首个节点称为头节点，将最后一个节点称为尾节点，尾节点指向空 None 。
- 环形链表：如果我们令单向链表的尾节点指向头节点（首尾相接），则得到一个环形链表。在环形链表中，任意节点都可以视作头节点。
- 双向链表：与单向链表相比，双向链表记录了两个方向的引用。双向链表的节点定义同时包含指向后继节点（下一个节点）和前驱节点（上一个节点）的引用（指针）。相较于单向链表，双向链表更具灵活性，可以朝两个方向遍历链表，但相应地也需要占用更多的内存空间。
