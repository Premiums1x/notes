1.内连接：
*内连接查询的是两个表交集部分*

语法：
![[Pasted image 20260413165213.png]]


## !!!：表别名不能加'',字段别名可以加，但不建议，建议直接写别名或者用\`\`包裹。

隐式：(给表起别名和给字段起别名同理，！！但起别名后，后面的条件语句只能用别名，而不能用原表名)
`select e.name, d.name from emp e ,dept d where d.id = e.dept_id;`

显式：
条件和表都一样，语法形式不一样：
表1 [INNER] JOIN 表2 ON 条件，INNER可省略
`select e.name,d.name from emp e inner join dept d on e.dept_id = d.id;`

二、子查询
![[Pasted image 20260413191316.png]]

1.标量子查询：
![[Pasted image 20260413191723.png]]

select查询得到单行单列的单个结果，可以作为条件传入：
```
select id from dept where name = '销售部';  
  
select * from emp where dept_id = (select id from dept where name = '销售部');
```

```
select emp.entrydate from emp where name = '方东白';  
  
select * from emp where entrydate >(select emp.entrydate from emp where name = '方东白');
```


2.列子查询(一列多行)
![[Pasted image 20260413192620.png]]

```
select id from dept where name = '销售部' or name = '市场部';  
  #返回得到的数据是一列多行的
  
select * from emp where dept_id in (select id from dept where name = '销售部' or name = '市场部');
```


all: 代表子查询返回的列表都要满足条件
```
#求财务部所有人工资：  
select emp.salary from emp where dept_id = (select id from dept where dept.name = '财务部');  
  
#求比财务部所有人工资都高的员工信息：  
select * from emp where salary > all ( select salary from emp where dept_id = (select id from dept where name = '财务部') );
```

any：子查询返回的列表只需有一个满足就行：
```
#研发部各员工的工资信息  
select salary from emp where dept_id = (select id from dept where name = '研发部');  
  
#子查询列表值任一满足即可:(大于最小值)  
select name from emp where salary > any (select salary from emp where dept_id = (select id from dept where name = '研发部'));
```


3.行子查询：
![[Pasted image 20260413195804.png]]
```
#张无忌的薪资、领导  
select salary,emp.managerid from emp where name = '张无忌';  
  
#想要动态匹配，但是返回的是“一行”的参数，不能一个个单独动态待入  
select * from emp where salary = 12500 and managerid = 1;  
  
#把参数由一个个写成"一行的"组合参数,从而实现一一对应，像insert时字段和值一一对应一般  
select * from emp where (salary,managerid) = (select salary,emp.managerid from emp where name = '张无忌');
```


4.表子查询：
![[Pasted image 20260413201911.png]]


*常用 IN 去 匹配 组合字段 和 得到的子表 的每一行*:
```
#查和鹿杖客、宋远桥职位、薪资相同的员工信息：  
#先拿到鹿杖客、宋远桥职位、薪资：  
select job,salary from emp where name='鹿杖客' or name='宋远桥';  
  
#设组合字段条件 取符合这这两条记录任一条记录的值  
select * from emp where (job ,salary ) in (select job,salary from emp where name='鹿杖客' or name='宋远桥');
```

*或把得到的子表当作表来和另一张表进行联查:*
```
#查入职时间在'2006-01-01'之后的员工信息，及其部门信息，  
#先拿入职时间在'2006-01-01'之后的员工信息：  
select * from emp where entrydate > '2006-01-01';  
  
#拿部门信息，需要联查，而我们得到的子表就可在from后作为其中一张表：(左外连)  
select e.*,d.* from  (select * from emp where entrydate > '2006-01-01') e left outer join dept d on e.dept_id = d.id;
```
