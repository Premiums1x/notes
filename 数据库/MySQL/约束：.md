**约束是作用于表中字段上**，可在建表/修改表时添加约束。

例：创建带有约束的表结构：
![[Pasted image 20260413145641.png]]

```
create table user(  
    id int primary key  auto_increment,  
    name varchar(10) not null unique ,  
    age int check (age >0 and age<120 ),  
    status char(1) default '1',  
    gender char(1)  
) comment '用户表';
```

# 外键约束
外键约束用于让两张表之间的数据建立连接，从而保证数据一致性、完整性。
![[Pasted image 20260413150713.png]]

拥有外键的表称为子表，也称为从表；
而外键所关联的主键对应的表称为父表，也称主表。

**外键约束的添加**：
1.建表时：
![[Pasted image 20260413151936.png]]

2.建完表后再想添加：
![[Pasted image 20260413152022.png]]
eg：
 `alter table emp add constraint fk_emp_dept_id foreign key (dept_id) references dept(id);`


**删除外键约束**：
![[Pasted image 20260413152559.png]]
eg:
`alter table emp drop constraint fk_emp_dept_id;`
