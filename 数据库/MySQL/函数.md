`DATE_ADD()举例：`
`select date add(now() INTERVAL 70 MONTH);`
INTERVAL固定，加上想要添加的时间周期，再加上时间单位

`DATEDIFF(date1,date2)`:的值是date1 - date2的天数 


查询每位员工入职天数，并根据入职天数降序排序：
`select name, emp.entrydate,datediff(now(),emp.entrydate) as '入职天数' from emp order by '入职天数' desc;`

![[Pasted image 20260413113129.png]]

`IFNULL`时，如果第一个参数为'',也返回'',只有第一个参数为null时，才返回第二个参数。


CASE WHEN：匹配字段的范围（把范围匹配写成表达式）


CASE 字段 WHEN：给字段精准匹配值
```
#上海/北京: 一线城市，否则二线城市  
select name,  
       (case workaddress when '北京'  then '一线城市' when '上海' then '一线城市' else '二线城市' end) as '工作城市'  
from emp;
```
