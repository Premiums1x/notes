## 一、项目概述

**账单小屋** 是一个面向个人记账场景的 Vue 3 应用，采用本地存储和 Mock 后端的设计模式，支持多账户数据隔离。

### 技术栈

| 类别 | 技术 |
|-----|------|
| 框架 | Vue 3 (Composition API) |
| 构建工具 | Vite 5 |
| 状态管理 | Pinia |
| 路由 | Vue Router 4 |
| UI 组件库 | Element Plus |
| 图表库 | ECharts |
| HTTP | Axios（自定义 Mock Adapter） |

### 核心特点

- **多账户隔离**：每个账户拥有独立的账单、预算和统计数据
- **本地持久化**：使用 localStorage 存储所有数据
- **Mock 后端**：自定义 Axios Adapter 模拟 API，无需真实后端
- **路由守卫**：登录状态校验与自动重定向

## 四、路由守卫流程

```
用户发起路由跳转
    ↓
┌─────────────────────────────────────────┐
│  router.beforeEach 守卫执行             │
└─────────────────────────────────────────┘
    ↓
【步骤 1】await store.ensureSession()
    ├─ 首次：sessionChecked = false
    └─ 后续：sessionChecked = true（跳过）
    ↓
【步骤 2】GET /api/auth/session
    ├─ 返回 { authenticated: true/false }
    └─ 若有登录账户，返回账户信息
    ↓
【步骤 3】设置 authenticated = session.authenticated
    ↓
【步骤 4】检查目标路由
    ↓
    【情况 1】目标路径是 /login
        ├─ 已登录 → 跳转 /records
        └─ 未登录 → 放行（显示登录页）
    ↓
    【情况 2】目标路径不是 /login
        ├─ 未登录 → 跳转 /login
        └─ 已登录 → 继续
    ↓
【步骤 5】检查 initialized
    ├─ initialized = true → 放行
    └─ initialized = false → await store.initialize()
    ↓
【步骤 6】返回 true（允许访问）
```

## 五、Mock 后端机制

### 5.1 Axios Mock Adapter

项目使用自定义的 Axios Adapter 来模拟后端 API：

```javascript
// src/api/http.js
const http = axios.create({
  baseURL: "/api",
  timeout: 8000,
  adapter: mockLedgerAdapter  // ← 自定义 adapter
});
```

### 5.2 Mock Adapter 工作原理

```
HTTP 请求发出
    ↓
进入 mockLedgerAdapter(config)
    ↓
【步骤 1】模拟延迟 120ms
    ↓
【步骤 2】解析请求
    ├─ method (get/post/put/delete)
    ├─ path (如 /auth/login)
    └─ body (请求体)
    ↓
【步骤 3】加载 state
    ├─ 从 localStorage 读取
    └─ 格式化与数据清洗
    ↓
【步骤 4】路由匹配
    ├─ if (method === "post" && path === "/auth/login")
    ├─ if (method === "get" && path === "/ledger")
    ├─ if (method === "post" && path === "/records")
    └─ ...
    ↓
【步骤 5】执行对应逻辑
    ├─ 数据验证
    ├─ 状态修改
    └─ saveState(state)
    ↓
【步骤 6】返回响应
    ├─ 成功：ok(config, data, status)
    └─ 失败：fail(config, message, status)
```

## 七、筛选与数据流

### 7.1 账单数据流转

```
records (所有账单)
    ↓
monthRecords (按月份筛选)
    ↓
recordsAfterFilter (按类型/日期筛选)
    ↓
groupedRecords (按日期分组)
```

### 7.2 筛选计算

```javascript
// 1. 月份筛选
monthRecords = records.filter(item => item.date.startsWith(month.value))

// 2. 类型筛选
if (typeFilter !== "all") {
  list = list.filter(item => item.type === typeFilter)
}

// 3. 日期筛选
if (dateFilter === "today") {
  list = list.filter(item => item.date === today)
} else if (dateFilter === "last7") {
  list = list.filter(item => 近7天内)
} else if (dateFilter === "custom") {
  list = list.filter(item => item.date === dateValue)
}

// 4. 日期分组
groupedRecords = 按日期分组，计算每日净额
```

### 7.3 汇总数据计算

```javascript
// 本月收入
summaryIncome = monthRecords
  .filter(item => item.type === "income")
  .reduce((sum, item) => sum + item.amount, 0)

// 本月支出
summaryExpense = monthRecords
  .filter(item => item.type === "expense")
  .reduce((sum, item) => sum + item.amount, 0)

// 预算剩余
summaryRemain = budget - summaryExpense
```

```
    ↓
┌─────────────────────────────────────────┐
│  尝试读取主存储 key                  │
│  "ledger-project-v4"                  │
└─────────────────────────────────────────┘
    ↓
    ├─ 读取成功 → sanitizeState() → 返回
    │
    └─ 读取失败 → 尝试迁移旧数据
        ↓
        遍历 LEGACY_KEYS:
        ├─ "ledger-project-v3"
        └─ "ledger-project-v2"
        ↓
        ├─ 有旧数据 → 升级格式 → 保存新 key
        └─ 无旧数据 → 创建默认账户
            ↓
            默认账户: demo / 123456
```
