## 三、 核心功能实现与技术复盘

### 1. 侧边栏：列表渲染与点击高亮

**目标**：生成菜单，点击哪个哪个变红。

**关键代码**：

HTML

```
<li 
  v-for="(item, index) in menus" 
  :key="item.name"
  :class="{ active: activeIndex === index }" 
  @click="handleMenuClick(index)"
>
  {{ item.name }}
</li>
```

JavaScript

```
// Script Setup
import { ref } from 'vue';

const activeIndex = ref(0); // 响应式变量
const menus = [{name: '发现'}, {name: '视频'}];

const handleMenuClick = (index) => {
  activeIndex.value = index; // 修改 ref 的值
};
```

**知识点解析**：

- **`v-for` 的参数传递**：`v-for="(item, index)"` 生成的 `index` 是实参，直接传给 `@click` 绑定的函数。

- **跟在v-for后的不论是元素还是属性，都是“迭代的”**：v-for是让每个子元素“都有”的

- **动态 Class**：`:class="{ active: A === B }"`。这意味着：如果 `A === B` 为真，则加上 `active` 类名。这是数据驱动样式的核心。
    

### 2. 推荐歌单：CSS Grid 布局 (今日高光)

**目标**：实现响应式的九宫格歌单墙。

**为何不用 Flex？** Flex 是“一维”的，处理换行对齐很麻烦。Grid 是“二维”的，不仅能对齐，还能自动计算一行放几个。

**核心 CSS (一句顶一万句)**：

CSS

```
.playlist-container {
  display: grid;
  /* 魔法代码：自动填充，每列最小140px，最大1fr(平分剩余空间) */
  grid-template-columns: repeat(auto-fill, minmax(140px, 1fr)); 
  gap: 20px;
}
```

- **`minmax(140px, 1fr)`**：保证了卡片不会被压得太扁，也不会留太多白。
    
- **`auto-fill`**：浏览器根据屏幕宽度自动计算列数，无需媒体查询。
    

### 3. 底部播放条：状态切换

**目标**：点击播放按钮，图标在 ▶️ 和 ⏸️ 之间切换。

## 四、 深度理解 Vue 响应式原理 (Ref)

### 1. 经典报错回顾

**错误代码**：

JavaScript

```
const activeIndex = ref(0);
activeIndex = 1; // ❌ Uncaught TypeError: Assignment to constant variable.
```

**原因**： `activeIndex` 是用 `const` 声明的**指针**，不能修改指针指向。

**修正**：

JavaScript

```
activeIndex.value = 1; // ✅ 修改指针指向对象内部的 value 属性
```

### 2. 科班视角解读

- **Ref 是什么**：Vue 为了拦截 JS 基本类型（number, string）的读写，把它们包在一个对象里（Wrapper）。
    
- **`.value` 的本质**：它是对象的 `Setter` 函数。只有通过 `.value` 赋值，Vue 才能捕获到数据变化，从而触发视图更新。
    
- **记忆口诀**：
    
    - 在 `template` (HTML) 里：**不用**写 `.value` (Vue 自动解包)。
        
    - 在 `script` (JS) 里：**必须**写 `.value`。
