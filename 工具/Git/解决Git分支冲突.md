如果我们在不同分支修改了相同的内容（如修改了同一个文件的同一处代码），这时合并就会产生冲突。
- 发生冲突时
`git status`：可查看发生冲突的文件
`git diff`:可查看发生冲突的具体内容
`git merge --abort`：可终止合并
发生冲突时，需要我们手动决定合并过程中保存的内容，再进行提交
