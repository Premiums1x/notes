1.`git branch`:查看仓库中的分支，* 为当前所在分支。
2.`git branch 分支名`：新建分支
3.`git checkout 分支名`：切换分支（默认）,也有恢复文件的作用，容易产生歧义。
现有专门切换分支的命令：`git switch 分支名`。
4.将其他分支合并到当前分支中：`git merge 分支名`，当前所在分支即为合并后的目标分支。(合并后分支依然存在，除非自行删除)
合并的结果就是：合并的目标分支在合并后在末尾会新增一次提交，然后两条分支像溪流一样“汇集“在一起。
5.Git中查看分支图：`git log --graph --oneline --decorate --all`
6.删除分支：
>`git branch -d 分支名`：删除已进行合并操作的分支
>`git branch -D  分支名`:强制删除分支（无论合并否）

注：在另一分支完成了某个功能后，需合并到主线，否则主线（内容）不会更新。
