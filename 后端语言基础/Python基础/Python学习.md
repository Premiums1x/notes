**多个条件判断**：elif
```python

```

- 一旦进入一个分支，就不会再看同一层级下的其他条件判断，也就是只会执行第一个为真的条件语句。

### 数据结构
 1. 列表（即数组）！！**可以同时存储不同类型的数据**
	 字面量：[ ]
	- 可用方法追加：
		items.append("xxx")
	- 列表是可变的，不同于改变基本数据类型的值时要重新赋值，
	   对列表使用方法，可以直接改变列表的内容。
	**注意：方法是该数据结构作为主体去调用方法；而函数则是该数据结构作为函数操作对象**
	- 删除：`remove("列表中的值") 方法`
	- 获取长度`len()函数`
	- 访问特定元素：列表[index]
	- 求最大、最小值：max(),min()函数
	- 排序：sorted()函数，！返回新列表而不改变原列表

2. 字典（可变），字面量{ }
	- 存储键值对，键是用来查找值的。键值对格式：`key:value`，若有多个用逗号相隔
	- 使用：`test = {"张伟":25}`;
	- 访问对应键的值`字典名[键]`：`test["张伟"]`，键必须是不可变元素，列表`[]`不能作为键。
	- 往字典里存新的键值对：`test["newName"] = xxx`,更新值也是同样的操作，字典中没有这个键的话就是新增键值对，有的话就是更新这个键的值。
	- 查找字典中有无某个键：`"key" in 字典名`，返回布尔值。
	- 删除键值对：`del 字典名["key"]`,若键不存在则报错
	- 获取字典长度：`len()`函数。
	- 字典方法：
		字典名.keys()   返回所有键
		字典名.values()  返回所有值
		字典名.items()  返回所有键值对。在for循环中，字典中的每个键值对会被返回成一个元组

3. 元组：如果需要多个条件才能区分开不同的键：用到元组`()`，元组是不可变的。
	使用示例：
	```python
	contacts={
	("张伟",26):xxx
	("张伟",35):xxx
	("张伟",40):xxx
	}
	```
	此时整个元组作为键，查找时：`contacts[("张伟",26)]`

### 格式化字符串
- 不论哪种方法，规定浮点数精度时，直接在花括号内加冒号: ,后面跟上精度和f，如{score:.2f}，就是用score作关键字进行替换，替换的参数是一个浮点数，在此限定只保留两位有效数字。
1. format()方法:
	格式:`字符串.format(参数1,参数2)`
	例子：
	```python
	"adawdad{0}adlajdwal{1}.format(参数1,参数2)"
	```
	  format括号里的各个参数就是要替换的内容；在字符串中，需要进行替换的位置，要用{}表示，{}中放入”下标“，表明要替换的内容是第几个参数。
	  如{0}处就表示要在此位置，用参数1进行替换。

	**还有使用关键字注明的方法**：
	```python
	"我司十四说四十水水{current_year},吴阿顺单纯性啊{current_month}".format(current_year = year,current_month =month)
	```
	字符串中用关键字作替换标识。在format括号里对关键字进行赋值，每个赋值语句等号左边是关键字，右边是参数。

2. f字符串
	在字符串前加f，字符串中用花括号括起来的内容会被直接求值。
	`f"今天是{year}年{month}月"`
	year和month会被直接求值。

### 面向对象 -封装、继承、多态
1. 面向过程：负责完成某个具体任务的代码，把要完成的目标任务按顺序拆分成一步步动作，配合函数实现。

2. 面向对象：先模拟现实世界，考虑事物的各个性质，然后将其抽象定义出一个”类“
	- （类里有属性和方法，属性就是”对象有什么性质“，方法就是”对象能做什么事情“，不同的属性和方法在创建对象时与对应对象相绑定）。
	- 更清晰地说，方法就是放在类里面的函数，属性就是放在类里面的变量。
	- **类是对象的模板，对象是类的实例**。
	- 类定义了对象有何种属性和方法，而对象拥有的具体属性可不尽相同。
	- 对象创建完成后可作为参数使用，传递给函数等等

#### 面向对象语法：定义属性与方法
1. 属性
```python
class 类名:
	#定义类的代码
	#如：
	def __init__(self):
	self.name = "Lambton"
```
- 类名：Pascal命名法，首字母大写分割单词。
- 类有一个特殊方法：**构造函数**，用来定义实例对象的属性，**必须被命名为`__init__（）`，注：前后各两个下划线。**
	即`def __init__(self)`,括号中可放任意数量参数，第一个参数必须是被占用的，被用来表示对象自身,约定俗成叫self，能把属性的值绑定在实例对象上。
	如`self.name = "Lambton"`说明是对象的name属性的值。若无self，会被视作普通变量的赋值，而不会将其看作是对象的属性。

2. 方法：
```python
	def 方法名(self):
		函数体
```
与普通函数定义类似，但有两点特定：
（1）写在类中，要有缩进
 （2）第一个参数被占用：self，用于表示对象自身，self在这里的作用：能让我们获取、修改与对象绑定的属性。


#### 创建对象：
`对象名 = 对应类名(参数..)`，`__init__ ()`方法会被调用，根据传入的参数给对象属性赋值，返回一个新的对象。
！注意self参数是无需传入的。
```python
class Cat:
	def __init__(self,cat_name,cat_age,cat_color):
	self.name = cat_name
	self.age = cat_age
	self.color = cat_color
	
cat1 = Cat("judy",2,orange)
```
如何灵活进行对象的属性值的绑定：把创建对象时的传入参数设置为对象的属性的值。

#### 访问对象属性、方法
`对象名.属性/方法`

#### 相比面向过程编程：直接聚焦于按步骤执行；面向对象编程，把事务先分解到对象身上，描述各个对象的作用，然后再让不同对象间交互。

#### 面向对象三大特性：
1.封装：
写类的时候，把内部实现细节隐藏；使用类时只通过外部接口访问。（接口相当于使用说明，告诉用户在使用类时，类里面有什么方法、某个方法是如何使用的、作用是什么，而无需关注源代码实现。）

2、继承
面向对象编程允许创建有层次的类，如子类、父类表示从属关系。父类的属性、方法都会被继承，无需反复定义。
```python
class 子类的名(要继承的父类的名):
	xxxx
```
此时，父类的`__init__()`构造函数(子类能继承有父类的属性的原因)和方法都会被子类继承。
- 子类没有`__init()__`构造函数时，会调用父类的属性。
- 子类若调用自身没有进行定义的方法时，会先在父类身上找方法。(如果调用的方法自身有，就用自身的)，即优先看所属的类有无该方法，没有再往上找父类的同名方法。

如果子类在继承父类的情况下，需要定义自身特定的属性，定义时应在子类的构造函数中用super()方法，该方法返回当前类的父类，再调用父类的构造方法。
例：父类Mammal中定义了name、sex，而子类Cat类有特定的tail属性：
```python
class Cat(Mammal) #继承Mammal父类
	def __init__(self,name,sex):#子类自己的构造函数，设置子类的实例对象的绑定属性
		super().__init__(name,sex):#调用父类构造函数来继承父类的属性，self指代当前类，无需传入。
		self.has_tail = True#设置子类特定属性
	

```

3.多态：无需判断，统一调用同一名称的方法。
同样的接口，因对象具体类的不同而有不同表现。（如写学生的类，小学生、大学生去继承这个大类。而二者就写作业这个方法而言，难度是不一样的，就不能写在父类里被两者都继承，而应该分别在子类中定义。），如果两个对象都有同样的方法，调用时无需担心方法有无冲突之类问题，因为不同对象所属的类不同，执行的方法也会不同。

### 文件操作：
1. 打开文件：open()函数
`open(文件路径,[操作方式],[encoding=xx])`
- 文件路径可是绝对也可是相对
- 操作方式是一个字符串，可选，常见"r"读取模式，"w"写入模式；不写则默认为读取模式;
- encoding选项是编码方式，表示用什么编码方式读取文件，一般为utf-8。

**`open（）`函数执行成功会返回一个文件对象，可以对其进行更多操作**：
>`read()方法`，读取文件所有内容，以字符串形式返回，每次read会记录下读取到的位置，如果继续read会紧接下去。
>可传一个数字作参数，限制程序读取多少字节。

>`readline()`方法，只读一行并返回字符串。

>`readlines()`方法，读取全部文件内容，把每行作为列表元素，返回一个列表。

因为read()和readline()方法都是读到最后时返回空字符串，所以，可以以此作为循环结束条件来循环读取文件。

#### 每次读完文件后应对文件对象使用close()方法，来关闭文件、释放系统资源。

#### 也有操作完文件后自动关闭的写法:
```python
with open(路径) as 对返回的文件对象的命名:
	对文件的操作
```
运行完缩进的（对文件进行操作的）代码块后文件自动被关闭。

2. 写文件：
```python
with open(路径,"w") as 对返回的文件对象的命名:
	对文件的操作
```
- 跟读文件类似,但需写明模式为“w”写入模式
- 且如果路径不存在会自动创建新文件，若文件存在则会**先清空文件再写入。**
- 注明encoding时是写入的编码标准

方法：
>write():里面传要写入的内容，注意多次调用不会自动换行，需手动写入换行符。

>如果不想清空重写就用"a"模式，附加模式。

>**只写"a"或"w"模式时**，都不能对返回的文件对象进行“读”操作，否则报错
>若要实现**同时读写**：使用“r+”模式，此时读写均可，（文件需要存在，否则报错找不到文件）且写入内容会被追加。应该有顺序是先读后写

#### 捕捉异常
```python
try:
	可能会报错的代码
except 可能的错误类型:
	错误发生时想执行的操作
#如：
except ValueError:
	xxx
except ZeroDivisonError:
	xxx
#捕捉所有错误类型：
except:
	xxx
	
else:
	放上当try的代码块里没有发生报错时要进行的操作
	
finally:
	这里写：无论try里的代码有无报错都会执行的代码，此处的代码最终无论如何都被执行
```
注意，只会执行第一个符合条件的分支代码。


####  测试
1. 断言
`assert 布尔表达式`，若布尔表达式值为True，则继续执行后面的代码；若为False，程序终止，后面的代码不再被运行。

2. python自带单元测试库：unittest,需引入。
- 实现代码和测试代码不能在同一程序中，要新建测试程序。并在测试程序中先导入unittest库`import unittest`,然后导入要测试的代码片段（如函数），若实现和测试文件都在同一文件夹下，使用`from 文件名 import 函数名`导入。
- 然后新建一个类，Test开头，需要继承unittest.TestCase类，以便使用这个类里的各自测试方法。`class TestXXX(unittest,TestCase):`
- 再然后写测试用例，每个测试用例都是一个以test开头的方法，*因为unittest.TestCase类会自动搜寻test开头的方法并将其视作测试用例。* 
```python
class TestMyAdder(unittest.TestCase):
#这是新建的测试类，需要self来访问各种父类方法
	def test_positive_with_negative(self):
		self.assertEqual(my_adder(5.3),8)
		#因为assert是用于测试的最基本函数，这些测试方法都只是相当于基于此进行额外封装。
		#此处传入的第一个和第二个参数相等则测试通过，否则不通过，程序不会“中断爆炸”
```

一切就绪后，在终端输入`python -m unittest`,该库会搜寻所有继承了unittest库里TestCase类的子类，并运行其中所有以test_开头的方法，然后展示运行结果。

-  对类进行测试时，因为要测试类中的不同方法，而测试用例间是独立的，需在每个测试用例中创建多个对象去访问不同方法。
- 这样会产生很多重复代码，因此我们可以通过`setUp()`方法先在当前的测试类中，把测试对象确定好，这样在后面写测试用例时，直接通过self来访问这个对象即可。`setUp()`方法, 会在执行所有test_开头的测试用例之前先执行一次。
