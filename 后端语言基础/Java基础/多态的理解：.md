这是一个非常核心且精彩的 Java 概念，叫做**多态（Polymorphism）**，具体体现为**向上转型（Upcasting）**。

简单直接的回答是：**因为“子类”本质上也是“父类”的一种。**

为了让你彻底理解，我们可以从**逻辑关系**、**内存原理**和**实际作用**三个维度来拆解。

### 1. 逻辑关系：Is-A 原则
在面向对象编程中，继承关系代表的是 **"Is-A"（是一个）** 的关系。
*   如果 `Dog`（狗）继承自 `Animal`（动物）。
*   那么：一只狗 **是一个** 动物。
*   但是：一个动物 **不一定是** 一只狗（它可能是猫）。

**代码示例：**
```java
class Animal {}
class Dog extends Animal {}

// ✅ 合法：因为狗肯定是动物，所以用“动物”类型的变量去接“狗”对象完全没问题
Animal a = new Dog(); 

// ❌ 非法：因为动物不一定是狗，不能用“狗”类型的变量去接通用的“动物”对象
// Dog d = new Animal(); 
```

**比喻：**
*   **父类变量** 就像是一个 **“水果”** 篮子。
*   **子类对象** 就像是一个具体的 **“苹果”**。
*   你可以把苹果放进水果篮子里吗？当然可以！因为苹果属于水果。
*   但是你不能把一个模糊的“水果”强行当成“苹果”（除非你确定它真的是苹果，这需要强制转换）。

---

### 2. 内存原理：变量存的是什么？
回顾我们刚才聊的，变量存储的只是**对象的地址（引用）**，而不是对象本身。

当你执行 `Animal a = new Dog();` 时：
1.  **右边 (`new Dog()`)**：在堆内存中真正创建了一个 **`Dog` 对象**。这个对象里既包含了 `Animal` 的部分（如名字、年龄），也包含了 `Dog` 特有的部分（如看家能力）。
2.  **左边 (`Animal a`)**：在栈内存中创建了一个变量 `a`，它的类型被限制为 `Animal`。
3.  **赋值 (`=`)**：把那个 `Dog` 对象的地址赋给 `a`。

**关键点来了：**
虽然变量 `a` 的类型声明是 `Animal`，但它指向的**真实对象**依然是 `Dog`。
*   **编译期看左边**：编译器只认 `Animal` 类型。所以通过 `a` 调用方法时，只能调用 `Animal` 类里定义的方法。如果 `Dog` 有特有方法（比如 `lookHome()`），编译器会报错，因为它觉得 `a` 只是个普通的动物，不会看家。
*   **运行期看右边**：JVM 在执行时，会发现 `a` 实际上指向的是一个 `Dog` 对象。如果你调用的方法在 `Dog` 中被**重写（Override）**了，JVM 会执行 `Dog` 版本的代码（这就是**动态绑定**）。

---

### 3. 为什么要这么做？（核心优势）
既然限制了只能调用父类方法，那直接用子类变量不就行了吗？为什么要用父类变量存子类对象？

这是为了实现 **解耦** 和 **通用性**。

#### 场景举例：动物园喂食
假设你有一个喂食方法，你希望它能喂所有的动物（狗、猫、老虎...），而不需要为每种动物写一个方法。

**如果不使用多态（不用父类变量）：**
```java
public void feedDog(Dog d) { ... }
public void feedCat(Cat c) { ... }
public void feedTiger(Tiger t) { ... }
// 每来一种新动物，你就得加一个新方法，代码会爆炸！
```

**使用多态（用父类变量）：**
```java
// 只需要写一个方法，参数是父类类型
public void feed(Animal a) {
    a.eat(); // 运行时，如果是狗就调用狗的eat，是猫就调用猫的eat
}

// 调用时，传入任何子类对象都可以
feed(new Dog());
feed(new Cat());
feed(new Tiger());
```
**好处**：
1.  **代码简洁**：只需要面向父类编程。
2.  **扩展性强**：明天新增了一个 `Pig` 类，只要它继承 `Animal`，上面的 `feed` 方法**一行代码都不用改**就能直接喂猪。

### 总结
1.  **合法性**：子类对象包含父类的所有特征，所以子类 **Is-A** 父类，可以用父类变量接收。
2.  **本质**：变量只是持有地址，真正的对象类型由 `new` 后面的类决定。
3.  **限制**：使用父类变量时，**编译时**只能访问父类定义的成员（为了安全），但**运行时**会执行子类重写后的方法（为了多态）。
4.  **目的**：为了让代码更通用、更易扩展，实现“面向接口/父类编程，面向实现/子类运行”。

这就是 Java 多态的精髓：**父类引用指向子类对象**。
