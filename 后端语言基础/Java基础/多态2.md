# Java 多态理解笔记

## 1. 我现在对多态的核心理解

### 我的原始理解

当写出：

Person p = new Student();

可以理解为：

- 实际创建出来的是 `Student` 对象
- 这个对象里有父类 `Person` 继承来的内容
- 也有 `Student` 自己扩展出来的属性和方法
- 但是变量 `p` 的类型是 `Person`
- 所以在使用 `p` 时，是“按父类的身份”去使用这个对象

### 更准确的说法

这句话在 Java 里叫：

**父类引用指向子类对象**

也就是：

- **对象的实际类型**是 `Student`
- **引用变量的类型**是 `Person`

所以：

- 编译器先看 `p` 是不是 `Person` 类型
- 运行时再看它实际指向的是不是 `Student` 对象

---

## 2. 多态最核心的一句话

### 我可以这样记

**编译看左边，运行看右边。**

对应到这句代码：

Person p = new Student();

- 左边 `Person`：决定**能不能调用**
- 右边 `new Student()`：决定**真正执行谁的方法**

这是理解多态最关键的一句话。

---

## 3. 为什么 `p` 不能直接访问 `Student` 新增的内容

例如：

class Person {  
    String name;  
  
    void eat() {  
        System.out.println("eat");  
    }  
}  
  
class Student extends Person {  
    int score;  
  
    void study() {  
        System.out.println("study");  
    }  
}

Person p = new Student();

这时：

p.name = "Tom";  // 可以  
p.eat();         // 可以

但是：

p.score = 100;   // 不可以  
p.study();       // 不可以

### 原因

不是因为对象里没有这些内容。

实际上对象本身是 `Student`，所以它**确实有**：

- `score`
- `study()`

但是 `p` 的类型是 `Person`，编译器检查 `p.xxx` 时，只看：

**`Person` 里有没有这个成员**

因为 `Person` 里没有 `score` 和 `study()`，所以不能通过 `p` 直接访问。

### 更准确的总结

**不是 Student 对象没有这些成员，而是 Person 类型的引用不允许你直接这样访问。**

## 4. 为什么父类方法被重写后，会执行子类的方法

例如：

class Person {  
    void say() {  
        System.out.println("我是Person");  
    }  
}  
  
class Student extends Person {  
    @Override  
    void say() {  
        System.out.println("我是Student");  
    }  
}

Person p = new Student();  
p.say();

输出：

我是Student

### 我的原始理解

父类的方法如果在子类中被重写了，那么虽然 `p` 被当作父类来使用，但因为实际创建的是 `Student` 对象，所以最后会用子类那个“更新后的”方法。

### 更准确的说法

你的理解方向是对的，但“更新后的方法”这个说法不够严谨。

更准确应该说：

**如果父类中的实例方法被子类重写，那么通过父类引用调用该方法时，运行时会根据对象的实际类型，执行子类重写后的版本。**

这里的关键不是“最新”，而是：

- 这个方法父类里本来就有
- 子类对它进行了**重写**
- 运行时发现对象实际是 `Student`
- 所以执行 `Student` 版本的方法

这就是多态。

---

## 5. 多态到底体现在哪

多态主要体现于：

**父类引用调用被子类重写的方法时，运行结果不同。**

也就是说，多态不是随便什么成员都“多态”。

真正经典的多态场景是：

Person p = new Student();  
p.say();

和

Person p = new Teacher();  
p.say();

虽然写法一样，都是 `p.say()`，但因为右边对象不同，最终执行的版本也不同。

这才叫：

**同一个父类引用，表现出不同子类的行为**

---

## 6. 多态成立的前提

一般要满足这几个条件：

### 1）要有继承关系

例如：

- `Student extends Person`
- `Teacher extends Person`

### 2）要有方法重写

子类要重写父类的方法，例如都重写 `say()`

### 3）要有父类引用指向子类对象

例如：

Person p = new Student();

如果没有这一步，就不算典型多态写法。

---

## 7. 多态中“能不能调用”和“调用谁”要分开看

这是最容易混的地方。

### 第一层：能不能调用

看左边引用类型。

例如：

Person p = new Student();  
p.say();

先看 `Person` 里有没有 `say()`。

- 有：可以写
- 没有：编译报错

### 第二层：真正调用谁

看右边实际对象类型。

- 如果对象是 `Student`
- 且 `Student` 重写了 `say()`
- 那就执行 `Student` 的 `say()`

### 一句话总结

**左边管资格，右边管执行。**

---

## 8. 子类新增方法为什么不属于多态

例如：

class Student extends Person {  
    void study() {  
        System.out.println("study");  
    }  
}

然后：

Person p = new Student();  
p.study();   // 报错

### 原因

因为 `study()` 不是父类里本来就有的方法，它是 `Student` 自己新增的。

而多态讨论的前提通常是：

**父类里先有这个方法，子类再去重写它。**

所以：

- **重写的方法**：有多态
- **子类新增的方法**：父类引用不能直接调，不属于这里说的多态

---

## 9. 如果一定要访问 Student 自己新增的内容怎么办

可以向下转型：

Person p = new Student();  
Student s = (Student) p;  
s.study();

这样就可以访问 `Student` 新增的成员。

### 但要注意

向下转型不是永远都安全。

例如：

Person p = new Person();  
Student s = (Student) p;   // 运行报错

因为这个对象本来就不是 `Student`。

### 更安全的写法

if (p instanceof Student) {  
    Student s = (Student) p;  
    s.study();  
}

---

## 10. 我当前理解中最准确的版本

你前面的理解可以整理成下面这段标准表达：

> `Person p = new Student();` 表示父类引用指向子类对象。  
> 实际创建的是 `Student` 对象，但引用类型是 `Person`，所以通过 `p` 只能直接访问 `Person` 中声明的成员。  
> 如果 `Student` 重写了 `Person` 的方法，那么运行时调用的会是 `Student` 重写后的版本，这体现了多态。

---

## 11. 一个完整例子

class Person {  
    String name = "PersonName";  
  
    void say() {  
        System.out.println("我是Person");  
    }  
}  
  
class Student extends Person {  
    int score = 100;  
  
    @Override  
    void say() {  
        System.out.println("我是Student");  
    }  
  
    void study() {  
        System.out.println("学生在学习");  
    }  
}

public class Test {  
    public static void main(String[] args) {  
        Person p = new Student();  
  
        p.say();      // 输出：我是Student  
        System.out.println(p.name); // 可以访问，因为Person里有name  
  
        // p.study();  // 报错，因为Person里没有study()  
        // p.score;    // 报错，因为Person里没有score  
  
        Student s = (Student) p;  
        s.study();    // 输出：学生在学习  
        System.out.println(s.score); // 100  
    }  
}

## 12. 我现在应该怎么记这部分

最后压缩成几句最好背、最好理解的话：

### ①

**`new Student()` 创建的永远是 Student 对象。**

### ②

**`Person p` 说明 p 要按 Person 类型的规则来使用。**

### ③

**通过父类引用，只能直接访问父类中声明过的成员。**

### ④

**如果子类重写了父类方法，运行时执行的是子类的方法。**

### ⑤

**多态的本质：同一个父类引用，指向不同子类对象时，调用同一个重写方法会表现出不同结果。**

---

## 13. 我当前最容易说错的地方

### 容易说错 1

“会调用最新的方法”

### 更准确

**会调用对象实际类型对应的重写方法。**

---

### 容易说错 2

“p 访问不到 Student 的成员，是因为对象里没有”

### 更准确

**不是对象里没有，而是引用类型限制了访问范围。**

---

### 容易说错 3

“只要是子类的方法都能多态调用”

### 更准确

**只有父类中声明、子类中重写的方法，才体现这里说的运行时多态。**

---

## 14. 一句总总结

**对象看右边，访问看左边，重写看运行。**

或者写得更完整一点：

**父类引用可以指向子类对象；编译时按父类检查，运行时按实际对象执行重写方法，这就是多态。**
