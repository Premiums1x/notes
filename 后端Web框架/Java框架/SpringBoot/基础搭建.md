### 编写请求控制类：
![[Pasted image 20260422193300.png]]
- **注解是重中之重：** 加上RestController才表明这是一个请求控制类，能对url访问作出响应
- 如何响应？**请求控制类中的方法**：用RequestMapping(‘请求地址’)注解标识此为请求处理方法
- 方法接收的参数即为浏览器端传的请求参数，return返回值即为浏览器接收到的响应数据。

启动类主方法启动服务端：
