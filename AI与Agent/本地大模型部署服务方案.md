1. `vllm`：高性能py库，通过 PagedAttention 等先进技术，可以实现比标准 Transformers 实现高出数倍的吞吐量。

本地部署服务：

- `pip install vllm`
- 命令行启动服务:`python -m vllm.entrypoints.openai.api_server \ --model Qwen/Qwen1.5-0.5B-Chat \ --host 0.0.0.0 \ --port 8000`
- 在`localhost:端口/v1` 地址上暴露服务

2. `Ollma`: 下载客户端，命令行运行`ollama run MODEL_NAME` 模型不存在则会下载，若存在则启动服务。默认会在`http://localhost:11434/v1` 地址上暴露 OpenAI 兼容的 API 接口。
